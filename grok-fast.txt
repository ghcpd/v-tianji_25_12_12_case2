### All Source Code Files

**Key files created:**

- `src/data/products.ts`: Mock product data with 8 items across categories like Electronics, Sports, Home, Accessories.
- `src/context/CartContext.tsx`: React context for cart state management with reducer for add, remove, update quantity, clear cart.
- `src/components/Header.tsx`: Header with logo, title, and cart icon with item count badge.
- `src/components/ProductCard.tsx`: Product display card with image, details, price, and add to cart button with animations.
- `src/components/ProductList.tsx`: Grid layout of product cards with staggered animations.
- `src/components/CartItem.tsx`: Individual cart item with quantity controls and remove button.
- `src/components/CartModal.tsx`: Sliding cart modal with item list, total, and checkout/clear buttons.
- App.tsx: Main app component wrapping with CartProvider and layout.
- index.css: Tailwind CSS import for styling.
- `src/test/CartContext.test.tsx`: Unit tests for cart reducer logic.
- `tests/cart.spec.ts`: E2E test for app loading and basic elements.

### All Test Files

- Unit tests: `src/test/CartContext.test.tsx` - Tests cart reducer for adding items and quantity increase.
- E2E tests: `tests/cart.spec.ts` - Basic test to check app loads and displays header and products.

### All Configuration Files

- package.json: Dependencies for React, Vite, Tailwind, Framer Motion, Lucide React, Vitest, Playwright, Testing Library.
- vite.config.ts: Vite config with React plugin and test setup.
- `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`: TypeScript configurations.
- `eslint.config.js`: ESLint configuration.
- `.gitignore`: Git ignore patterns.

### Commands Used to Install, Test, and Run

1. `npx create-vite@latest . --template react-ts` - Create Vite React TypeScript project.
2. `npm install -D tailwindcss postcss autoprefixer` - Install Tailwind CSS.
3. `npx tailwindcss init -p` - Initialize Tailwind (though v4 doesn't require config).
4. `npm install framer-motion lucide-react` - Install animation and icon libraries.
5. `npm install -D vitest jsdom @testing-library/jest-dom @testing-library/react @testing-library/user-event` - Install testing libraries.
6. `npm install -D @playwright/test` - Install Playwright for E2E.
7. `npm run build` - Build the project.
8. `npm test -- --run` - Run unit tests.
9. `npm run dev` - Start development server.
